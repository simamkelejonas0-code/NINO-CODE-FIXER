# NINO CODE FIXER

Offline tool for Termux. Paste a Termux error block, get a complete bash script to fix it.

## Usage

1. Paste the full Termux output into the app
2. Tap FIX
3. Copy the full output script
4. Run it in Termux

## Fixes

- aapt2 architecture mismatch
- d8 missing class files
- javac cannot find symbol
- Permission denied for /tmp
- git push rejected

## Build

python3 build_html.py
bash build_apk.sh
