NINO CODE FIXER

Offline tool for Termux. Paste a Termux error block, get a complete bash script to fix it.

Usage:
1. Paste full Termux output
2. Tap FIX
3. Copy full output script
4. Run it in Termux

Build:
python3 build_html.py
bash build_apk.sh
